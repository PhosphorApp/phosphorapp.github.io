Phosphor

A media player and jukebox for virtual pinball cabinets — and a capable stand-alone desktop media player.

Plays media across your cabinet's screens (playfield, backglass, topper, DMD) with audio-reactive animated visuals and optional DOF cabinet lighting.

Download latest release View on GitHub

Up to 4 screens, position anywhere: UI, video player, visualizations windows.

Features

Many media sources

Pluggable sources: YouTube, Plex, Jellyfin, Emby, Vimeo, Dailymotion, SoundCloud, Twitch, SiriusXM, iHeartRadio and a Local Folder source.

Multi-screen layout

Independent, individually positioned and sized windows for Playfield, Backglass, Topper and DMD. Also works in single-screen desktop mode.

Audio-reactive visuals

Visualizations driven by the audio, which also drive effects and DOF lighting.

DOF lighting

Triggers cabinet solenoids and LEDs via DirectOutput Framework through an isolated bridge process.

Customizable icons

Emoji tile icons from selectable font sets (Segoe, Twemoji, OpenMoji, Fluent Flat) in Color, Desaturated, Silhouette or Themed styles.

Caching

Optional video pre-fetch, thumbnail, playlist and category caches reduce network round-trips for a smoother experience.

Controller input

DirectInput joystick/gamepad support alongside keyboard bindings for button-box navigation.

Extensible

Additional plug-ins can be developed and loaded at runtime.

Get started

  1. Download the latest release and extract the ZIP to a folder of your choice. Settings are stored locally in that folder for portability. The first run may take a few seconds.
  2. Open Settings to configure window positions, source plug-ins and optional server details.

Requirements

  • Windows 10/11 (x64)
  • DirectOutput Framework — optional, for DOF lighting

Everything else (LibVLC, ffmpeg, projectM) is bundled. No separate VLC install is required.

Plug-ins & developers

Phosphor is built around a plug-in contract, so new media sources can be added without touching the app.

  • phosphor-plugins — the bundled source plug-ins.
  • phosphor-abstractions — the plug-in contract, published to NuGet as Phosphor.Plugin.Abstractions.
